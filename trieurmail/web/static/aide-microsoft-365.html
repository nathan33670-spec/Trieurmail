Connexion Microsoft 365 / Exchange

Comment connecter Trieurmail à votre boîte Outlook (Microsoft 365, Exchange Online ou outlook.com), à quoi servent l'« ID d'application » et l'« organisation (tenant) », et comment résoudre les erreurs courantes.

1. Connexion rapide (cas général)

Dans la plupart des cas, aucune configuration n'est nécessaire :

  1. Dans Trieurmail, ouvrez Réglages → Messagerie et choisissez Microsoft 365 / Exchange.
  2. Cliquez sur Se connecter avec Microsoft. Un code (ex. ABCD1234) s'affiche.
  3. Ouvrez la page microsoft.com/devicelogin, collez le code puis connectez-vous avec votre compte (MFA comprise).
  4. Acceptez les autorisations demandées. Trieurmail détecte la connexion en quelques secondes.
Par défaut, Trieurmail utilise l'application publique de Microsoft « Microsoft Graph Command Line Tools » (ID 14d82eec-204b-4c2f-b7e8-296a70dab67e). Vous n'avez donc rien à créer, sauf si votre organisation bloque cette application (voir section 5).

2. Les deux paramètres avancés

ChampÀ quoi il sertValeur par défaut
ID d'application (client ID)Identifiant de l'application enregistrée chez Microsoft au nom de laquelle Trieurmail demande l'accès à votre boîte. Format : xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.14d82eec-204b-4c2f-b7e8-296a70dab67e (Graph Command Line Tools)
Organisation (tenant)L'annuaire Microsoft (Entra ID) qui authentifie votre compte.organizations

Valeurs possibles pour le tenant :

  • organizations — n'importe quel compte professionnel ou scolaire (Microsoft 365).
  • consumers — comptes personnels uniquement (outlook.com, hotmail.com, live.com).
  • common — comptes professionnels et personnels.
  • Le domaine de l'entreprise (ex. entreprise.fr) ou son ID d'annuaire (GUID) — obligatoire si l'application utilisée n'accepte qu'une seule organisation.
Compte personnel outlook.com / hotmail ? Saisissez consumers (ou common) comme tenant : avec organizations, Microsoft refuse les comptes personnels.

3. Trouver votre organisation (tenant)

  • Le plus simple : la partie après le @ de votre adresse professionnelle (ex. entreprise.fr). Trieurmail accepte aussi l'adresse complète et en extrait le domaine.
  • L'ID d'annuaire exact : Microsoft Entra → Vue d'ensemble, champ ID de locataire (Tenant ID). Sans accès au portail, demandez-le à votre service informatique.
  • Référence Microsoft : Trouver votre ID de locataire.

4. Créer votre propre application (client ID)

Utile si l'application par défaut est bloquée, ou si votre service informatique préfère une application dédiée. Il faut un compte autorisé à enregistrer des applications (souvent un administrateur ; pour un compte personnel, n'importe quel compte Microsoft convient).

  1. Ouvrez Microsoft Entra → Inscriptions d'applications (ou le même écran dans le portail Azure) puis + Nouvelle inscription.
  2. Nom : par exemple « Trieurmail ».
  3. Types de comptes pris en charge :
    • « Comptes dans cet annuaire organisationnel uniquement » → indiquez ensuite votre domaine ou ID d'annuaire comme tenant ;
    • « Comptes dans un annuaire organisationnel » → tenant organizations ;
    • « … et comptes Microsoft personnels » → tenant common (ou consumers pour un compte personnel).
  4. URI de redirection : laissez vide (la connexion par code n'en a pas besoin). Cliquez sur S'inscrire.
  5. Dans Authentification (ou Authentication), section Paramètres avancés, activez Autoriser les flux de clients publics (« Allow public client flows ») → Oui, puis Enregistrer. Sans cela, la connexion échoue avec l'erreur AADSTS7000218.
  6. Dans Autorisations de l'API → Ajouter une autorisation → Microsoft Graph → Autorisations déléguées, cochez : User.Read, Mail.ReadWrite, Mail.Send, offline_access. (Facultatif : un administrateur peut cliquer sur Accorder le consentement administrateur pour toute l'organisation.)
  7. Revenez sur Vue d'ensemble et copiez :
    • ID d'application (client) → champ « ID d'application (client ID) » de Trieurmail ;
    • ID de l'annuaire (locataire) → champ « Organisation (tenant) » (si l'application est mono-organisation).
  8. Dans Trieurmail : Réglages → Messagerie → Paramètres avancés, collez les valeurs, puis Se connecter avec Microsoft.

Références Microsoft : Inscrire une application · Flux d'autorisation par code d'appareil · Autorisations Microsoft Graph.

5. Si l'administrateur doit approuver

De nombreuses organisations interdisent aux utilisateurs d'autoriser seuls une application. Le message « approbation d'un administrateur requise » (AADSTS65001 / AADSTS90094) apparaît alors. Deux options :

  • Demander à l'administrateur d'accorder le consentement pour l'application utilisée (par défaut 14d82eec-204b-4c2f-b7e8-296a70dab67e) : Accorder le consentement administrateur.
  • Lui demander de créer une application dédiée (section 4) et de vous communiquer son ID d'application et l'ID d'annuaire.

6. Messages d'erreur et solutions

Les erreurs Microsoft commencent par un code AADSTSxxxxx. Le détail de chaque code est consultable sur login.microsoftonline.com/error et dans la liste officielle des codes.

7. Réseau, proxy et certificats

  • L'ordinateur doit pouvoir joindre https://login.microsoftonline.com et https://graph.microsoft.com.
  • Proxy d'entreprise : définissez la variable HTTPS_PROXY (ex. export HTTPS_PROXY=http://proxy.entreprise.fr:8080) avant de lancer Trieurmail.
  • Certificat refusé (« CERTIFICATE_VERIFY_FAILED ») : un proxy ou un antivirus inspecte le HTTPS avec un certificat interne. Installez truststore pour que Trieurmail utilise les certificats de votre système (pip install truststore), ou indiquez le certificat de l'entreprise via export SSL_CERT_FILE=/chemin/vers/certificat.pem.

8. Sécurité et déconnexion

  • Aucun mot de passe ne transite par Trieurmail : seul un jeton est conservé dans ~/.trieurmail/graph_token.json, lisible par vous seul.
  • Autorisations demandées : User.Read (votre nom et adresse), Mail.ReadWrite (lire, classer, créer des brouillons), Mail.Send (envoyer quand vous le demandez), offline_access (rester connecté).
  • Pour révoquer l'accès : Se déconnecter dans Trieurmail, et éventuellement retirer l'application depuis myapps.microsoft.com (compte pro) ou account.live.com/consent/Manage (compte personnel).
